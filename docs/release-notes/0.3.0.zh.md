# Umless 0.3.0

首个公开版本，也是首个提供 Windows 安装程序的版本。

## 新增

- Windows 安装程序（无需管理员权限）与免安装 zip；卸载时保留你的配置、记录和模型。
- 自动检查更新：发现新版本时在主界面和托盘提示，一键下载、校验并安装，装完自动重启；也可以跳过某个版本。
- 自定义热键：在设置里直接按下想用的键录制，支持任意单键或组合键（如 Ctrl + Space），并可调整「轻点与按住」的分界。
- 界面支持简体中文和英文，可跟随系统语言，切换立即生效；新手引导与七步功能导览可在「设置 → 关于」里重看。
- 提示音设置：总开关、音量，开始 / 停止 / 完成 / 出错分别可选预设音、静音或本地 WAV。

## 改进

- 不配置大模型时，识别结果里的英文也会自动改成正常大小写（缩写保持大写，术语表里的词按术语表的写法）。
- 日志不再记录你说的原文和输出，只记字数和耗时。
- 麦克风打不开时给出明确提示，不再一直停在「正在聆听」；插拔耳机后按当前设备录音。
- 粘贴失败时这段话仍会记入历史，可以在历史里复制。
- 默认应用黑名单补充了更多密码管理器与系统凭据输入框。

## 修复

- 删除确认框里按回车会直接删除。
- 场景规则在清空某一行后删除另一行时会删错。
- 切换页面再回来时可能重复开始诊断或重复下载模型。
