# Umless 0.3.1

A maintenance release to exercise in-app updates, with one small fix. Update from 0.3.0 in one click under Settings → About.

## Fixed

- If a downloaded installer was modified or truncated before installing, Umless now says the installer failed verification and asks you to download again, instead of a vague "download the update first".
