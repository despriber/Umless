# Umless 0.3.0

The first public release, and the first with a Windows installer.

## New

- Windows installer (no admin rights needed) and a portable zip; uninstalling keeps your settings, history and models.
- Automatic update checks: new versions are announced in the app and the tray; download, verify and install in one click, and Umless restarts itself. You can also skip a version.
- Custom hotkey: press the key you want in Settings to record it — any single key or a shortcut such as Ctrl + Space — and tune the tap-vs-hold threshold.
- Simplified Chinese and English UI that can follow the system language and switches instantly; the onboarding and the seven-step tour can be replayed from Settings → About.
- Sound settings: master switch, volume, and a preset, silence or your own WAV for start / stop / done / error.

## Improved

- Without an LLM, English in the transcript now gets normal casing (acronyms stay uppercase; glossary terms use your spelling).
- Logs no longer contain what you said or the output — only lengths and timings.
- A clear message when the microphone can't be opened instead of staying on "Listening"; recording follows the current device after plugging in a headset.
- If pasting fails, the dictation is still saved to History so you can copy it there.
- The default excluded-apps list covers more password managers and the Windows credential prompt.

## Fixed

- Pressing Enter in a delete confirmation deleted immediately.
- Scene rules could delete the wrong row after clearing another row.
- Leaving and returning to a page could start a second diagnosis or model download.
